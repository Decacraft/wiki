# 🧭 Bienvenue sur le Wiki de DecaCraft !

**DecaCraft** est un serveur Minecraft **freebuild en Play2Win** : ici, tout se gagne en jouant. Plus tu joues, plus tu progresses, et ton argent réel n'achète aucune puissance.

Ce wiki regroupe tout ce qu'il faut savoir pour bien débuter et profiter du serveur.

## 🚀 Pour bien débuter

1. **Lis le [règlement](/rules/)**. Il est court et évite bien des soucis.
2. **Rejoins le Discord** : c'est là que tu trouveras le staff, l'aide et les tickets.
3. **Découvre les [mondes](/world/)** : un monde pour construire, un monde pour récolter. Ne mélange pas les deux !
4. **Protège tes coffres** : ils sont verrouillés automatiquement.
5. **Gagne tes premiers Ð** en vendant tes minerais avec `/sell hand` ou `/sell inventory` (voir l'[économie](/economy/)).
6. **Monte de niveau** : chaque action te rapporte de l'XP, voir le [système Play2Win](/play-to-win/).
