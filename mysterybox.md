# Les Mystery Box

Les **Mystery Box** sont des coffres mystère installés au spawn. Avec une **clef**, tu les ouvres pour tenter de remporter un lot : à chaque ouverture, une surprise !

## En résumé

| | |
|---|---|
| **Pour ouvrir une box** | Une **clef** |
| **Où les trouver** | Au spawn : dans le **Bazar Mystère** et auprès des **PNJ métiers** |
| **Voir les lots** | Clic sur la box **sans clef** |
| **Obtenir des clefs** | Succès, vote ou achat (voir ci-dessous) |

## Obtenir des clefs

Il y a trois façons de se procurer de quoi ouvrir des box :

| Méthode | Détails |
|---|---|
| **Les récompenses de succès** | Certains succès donnent des clefs (voir `/succes` et `/reward`) |
| **Le vote** | Chaque vote te donne une **clef de vote**, à utiliser sur les box de vote (voir [Vote et Vote Party](/vote/)) |
| **L'achat** | Auprès du **marchand du Bazar Mystère** |

> **💡 Astuce :** les récompenses de vote sont obtenables **même hors ligne**.

## Ouvrir une box

1. Rends-toi au **spawn** : les box se trouvent dans le bâtiment du **Bazar Mystère**, et auprès de **PNJ exerçant un métier**, dispersés dans le spawn.
2. **Regarde les lots** en faisant un clic sur la box, **sans clef**.
3. **Ouvre la box** avec ta clef pour tenter ta chance.

## Les types de box

| Famille | Box |
|---|---|
| **Métiers** | Chasseur, Fermier, Bûcheron, Mineur, Éleveur |
| **Tiers** | Tier-1 (Commun), Tier-2 (Rare), Tier-3 (Epique) |
| **Spéciales** | Vote , Décoration |
